# تطبيق إدارة أحداث مع حجز تذاكر ومراقبة الحضور
==========================

## ملخص المشروع

تطبيق إدارة أحداث مع حجز تذاكر ومراقبة الحضور هو تطبيق مفتوح المصدر يهدف إلى تسهيل إدارة الأحداث والتقارير عن الحضور. يتيح التطبيق حجز تذاكر للأحداث ومراقبة الحضور في الوقت الحقيقي.

## هيكل المشروع

* `app/`: هيكل التطبيق
 + `models/`: تعريفات المॉडل
 + `controllers/`: واجهات التحكم
 + `routes/`: مسارات التطبيق
* `database/`: هيكل قاعدة البيانات
 + `migrations/`: عمليات التحديث
 + `seeds/`: بيانات العينة
* `docker/`: هيكل docker
 + `docker-compose.yml`: ملف docker-compose
 + `Dockerfile`: ملف docker
* `tests/`: اختبارات التطبيق

## تشغيل البيئة باستخدام docker-compose

1. تأكد من أن docker-compose مثبت على جهازك.
2. انتقل إلى مجلد المشروع.
3. تشغيل الأمر التالي:
bash
docker-compose up

4. افتح متصفحك ومرر إلى `http://localhost:8000` لفتح التطبيق.

## مكونات التطبيق

### مكونات قاعدة البيانات

* `events`: جدول الأحداث
 + `id`: رقم التعريف
 + `title`: العنوان
 + `date`: التاريخ
 + `time`: الوقت
* `tickets`: جدول التذاكر
 + `id`: رقم التعريف
 + `event_id`: رقم التعريف للحدث
 + `user_id`: رقم التعريف للمستخدم
* `attendances`: جدول الحضور
 + `id`: رقم التعريف
 + `event_id`: رقم التعريف للحدث
 + `user_id`: رقم التعريف للمستخدم
 + `attended`: حالة الحضور

### أدوار المستخدمين

* `admin`: مدير التطبيق
 + يمكنه إدارة الأحداث والتقارير عن الحضور
* `user`: مستخدم التطبيق
 + يمكنه حجز تذاكر للأحداث ومراقبة الحضور
